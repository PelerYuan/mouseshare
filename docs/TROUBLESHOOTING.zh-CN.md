## 点击“添加设备”后什么都没发现

自动发现使用 mDNS（多播 DNS），需要满足：

- 另一台电脑正在**共享**（已点击 *开始共享*，角色为 *被控端*）；
- 两台电脑在同一个网段：访客 Wi-Fi、VLAN 和部分路由器会阻止设备之间的多播（“客户端隔离”）；
- 没有防火墙拦截 UDP `5353` 端口。

如果仍然找不到，请**手动输入地址**：被控电脑的主区域会显示地址（例如 `192.168.1.20:7878`），
把它填入 **添加设备** 的 *地址* 栏。发现功能只是便利，连接从不依赖它。

## 提示“配对码错误”

控制端输入的配对码与被控电脑上显示的不一致。请检查是否输错相近字符（`0`/`O`、`1`/`I`/`L` 视为相同，没有问题），
以及复制的是否是*当前*配对码：在被控电脑上点击 **换新码** 会使旧码失效。在控制端侧栏选中该设备并修正配对码即可。

同一地址在一分钟内连续输错 5 次后，被控电脑会暂时忽略来自该地址的尝试，请等一分钟再试。

## 提示“无法连接，正在重试…”

控制端无法建立 TCP 连接。请依次检查：

1. 被控电脑正在运行，且 **开始共享** 已启动。
2. 地址和端口正确（默认端口 `7878`）。
3. 防火墙允许该端口的入站 TCP：
   ```bash
   sudo ufw allow 7878/tcp          # ufw
   sudo firewall-cmd --add-port=7878/tcp --permanent && sudo firewall-cmd --reload   # firewalld
   ```
4. 在控制端执行 `nc -vz <地址> 7878`，应显示 *succeeded*。

mouseshare 会以递增的间隔（1 秒到 15 秒）不断重试，问题解决后会自动恢复。

## 光标卡在另一台电脑上了

按 **Ctrl+Alt+Esc**（或你设置的返回快捷键）。这个快捷键由控制端处理，总能把你带回来。
如果另一台电脑休眠或断网，mouseshare 会在约 10 秒内发现并自动把光标还给你。

## 光标无法穿过屏幕边缘

- 确认画布上两块屏幕**相邻贴合**。拖动时它们会自动吸附；红色的“屏幕重叠”提示表示它们相交了。
- 设备旁的状态必须是 *已连接*。
- **边缘停留时间**（输入设置）要求光标在边缘停留相应时长。
- **拖拽时不切换** 会在按住鼠标按键时忽略边缘，请先松开。
- 屏幕大小不同时，只有真正与另一块屏幕相邻的那部分边缘可以穿过，可用 **对齐** 一键对齐。

## 按键输入的字符不对

mouseshare 按 X11 键码转发按键，所以两台电脑最好使用相同的键盘布局。如果不同（例如一台是美式、另一台是德式），
保留的是按键的*位置*，而字符取决于被输入那台电脑的布局。请在两台电脑上设置相同布局（`setxkbmap us`），
或接受字符跟随被控端布局。

## 剪贴板不同步

- 检查 **设置 → 剪贴板 → 共享剪贴板文本** 是否开启，修改后需重新开始共享。
- 只同步不超过大小上限（默认 256 KB）的**纯文本**，不同步图片和文件。
- 个别应用（某些终端、远程桌面窗口）只提供*主选区*（中键粘贴），而不是剪贴板。

## 窗口一片空白或图形界面无法启动

图形界面需要 OpenGL（`libgl1`）以及 X11 或 XWayland 显示。在虚拟机或最小化安装中可以尝试：

```bash
sudo apt install libgl1 libxkbcommon-x11-0 mesa-utils
LIBGL_ALWAYS_SOFTWARE=1 mouseshare-gui      # 强制使用软件渲染
```

在 Wayland 上，请在 XWayland 下运行 `mouseshare-gui`（多数桌面默认如此）；注意鼠标共享本身需要真正的 X11 会话。

## 中文显示为方框

安装 CJK 字体后重启应用：

```bash
sudo apt install fonts-noto-cjk        # 或 fonts-wqy-microhei
```

只有找到这类字体时，才会提供 *简体中文* 语言选项。

## 常见问题

**支持 Wayland 吗？** 暂不支持。Wayland 限制全局捕获和注入输入，需要另外的后端，参见[路线图](ROADMAP.zh-CN.md)。
大多数发行版的登录界面可以选择 “Xorg” / “X11” 会话。

**支持 Windows 或 macOS 吗？** 暂不支持，欢迎贡献（见路线图）。

**在公共 Wi-Fi 上安全吗？** 每条连接都用配对码认证并加密，网络上的其他人无法读取或注入输入。
但仍请把配对码当作密码对待，并优先使用可信网络。详见[协议与安全设计](PROTOCOL.zh-CN.md#安全设计)。

**两台电脑可以同时做控制端吗？** 一台电脑要么是控制端，要么是被控端。在侧栏切换角色即可互换。

**可以控制有多个显示器的电脑吗？** 可以，显示器会被自动检测，并在画布上显示为一组。

**会用到云服务吗？** 不会。一切都在局域网内的电脑之间直接进行，没有账号、服务器和遥测。

**设置存在哪里？** `~/.config/mouseshare/`，见[用户指南](USER_GUIDE.zh-CN.md#文件与配置)。

**可以不用图形界面吗？** 可以：`mouseshare` 命令共用同样的设置，见[命令行](USER_GUIDE.zh-CN.md#命令行)。

## 提交问题时需要收集的信息

请附上：

- `mouseshare --version` 的输出，以及你的发行版 / 桌面环境；
- 日志（打开图形界面的 **日志** 面板，或运行命令行并复制 stderr）；
- `~/.config/mouseshare/settings.toml`（可以分享，但**绝不要**分享 `pairing.toml`）；
- 你做了什么、期望什么、实际发生了什么。

然后通过[问题反馈表单](https://github.com/PelerYuan/mouseshare/issues/new/choose)创建 issue。
