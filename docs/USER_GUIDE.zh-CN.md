## 工作原理

每台电脑扮演两种角色之一：

- **控制端（Controller）**：拥有实体鼠标和键盘。一套设置里只有一个控制端。
- **被控端（Controlled / target）**：被控制端操控。数量不限。

当光标从控制端屏幕的某条边移出，而这条边在你的排列中紧挨着另一台电脑的屏幕时，鼠标、键盘和滚轮就会转发到那台电脑，
直到光标回来。剪贴板文字会在两个方向上自动同步。

## 安装

见 [README](../README.zh-CN.md#安装)。安装后，*mouseshare* 会出现在应用菜单里，`mouseshare-gui` 和 `mouseshare`
命令也在 `PATH` 中（使用压缩包安装脚本时，如果 `~/.local/bin` 不在 `PATH` 中，请自行添加）。

运行要求：每台电脑都运行 **X11** 会话，且电脑之间 TCP 互通（默认端口 `7878`）。

## 首次运行

第一次打开应用时，简短的引导会询问：

1. 这台电脑的**名称**（其他电脑会看到它）；
2. 它的**角色**：*控制其他电脑* 或 *被其他电脑控制*。

两者之后都可以修改；也可以在 **设置 → 常规 → 重新显示欢迎引导** 里再看一遍引导。

## 配对两台电脑

每台电脑只需配对一次。

1. 在**被控电脑**上，左侧栏选择 **被控端**，点击 **开始共享**。主区域会显示一个很大的**配对码**
   （例如 `7F3KD-9X2MQ`）和这台电脑在网络中的地址。
2. 在**控制端**，点击 **添加设备**。正在共享且可通过 mDNS 找到的电脑会出现在列表里，点击即可自动填入名称和地址。
   如果没有出现，请自己输入名称和地址（`192.168.1.20:7878`）。
3. 输入配对码，点击 **添加**。

配对码会被记住，下次只需点击 **开始共享**。配对码不区分大小写，标点会被忽略。如果需要换新的，
请先在被控电脑上停止共享，再点击 **换新码**，然后在控制端（在侧栏选中该设备）修改它的配对码。

> **为什么要配对码？** 配对码用来认证双方并生成加密密钥。不知道配对码的人，即使在共用的网络里，
> 也无法控制你的电脑或读取通信内容。详见[协议与安全设计](PROTOCOL.zh-CN.md#安全设计)。

## 排列屏幕

在控制端，画布把每台电脑显示为一组带标签的显示器。把**电脑拖动**到它相对你的电脑所在的位置：

- 屏幕组会**自动贴齐**最近的边，光标才能穿过。
- 使用侧栏的 **对齐**（顶部 / 居中 / 底部，或 左 / 居中 / 右）可一键对齐大小不同的屏幕。
- 有多个显示器的电脑作为一个整体移动，每个显示器保持真实相对位置。
- 滚轮缩放，拖动空白处平移，右下角按钮可缩放或适应窗口。
- 屏幕重叠时会用红色提示，请把它们拖开。

显示器尺寸在每次连接时自动检测，无需手动输入分辨率。

## 日常使用

1. 在每台电脑上点击 **开始共享**（或在设置里启用 **启动后自动开始共享**）。
2. 把光标推过屏幕边缘即可移动到相邻的电脑，从对面边缘推回即可返回。
3. 像平常一样输入、点击、滚动和使用剪贴板。

侧栏会显示每台电脑的状态：*连接中…*、*已连接 · 4 毫秒*、*配对码错误*、*无法连接，正在重试…*，
连接和断开时会弹出提示。如果某台电脑消失了（休眠、Wi-Fi 断开），mouseshare 会把光标还给你并自动重连。

**紧急返回：**随时按 **Ctrl+Alt+Esc**（可修改），光标和键盘立刻回到控制端。

## 设置参考

打开 **设置**（右上角齿轮图标）。更改会自动保存。标有 ⟳ 的选项在下次点击 **开始共享** 时生效。

### 常规

| 设置 | 说明 |
|---|---|
| 语言 | 自动、English 或简体中文。中文需要系统装有 CJK 字体（`fonts-noto-cjk`）。 |
| 主题 | 自动（跟随桌面）、深色或浅色。 |
| 强调色 | 蓝、紫、青、绿、橙或粉。 |
| 界面大小 | 80 %–160 %。 |
| 登录时自动打开 | 添加自启动项（`~/.config/autostart/mouseshare.desktop`）。 |
| 启动后自动开始共享 | 应用一打开就开始共享。 |

### 输入

| 设置 | 说明 |
|---|---|
| 返回快捷键 ⟳ | 把光标拉回控制端。默认 `Ctrl+Alt+Esc`。格式：修饰键 `Ctrl`、`Alt`、`Shift`、`Super` 加一个按键，例如 `Ctrl+Shift+F12`。 |
| 边缘停留时间 ⟳ | 光标需要在边缘停留多久（0–1000 毫秒）才切换，避免误触。 |
| 拖拽时不切换 ⟳ | 按住鼠标按键时忽略屏幕边缘。 |
| 自然滚动 ⟳ | 反转被控电脑上的滚轮方向。 |

每台设备（在侧栏选中它）还有：**指针速度**（0.25×–4×，用于鼠标手感过快或过慢的电脑）、设备**地址**和**配对码**。

### 剪贴板

| 设置 | 说明 |
|---|---|
| 共享剪贴板文本 ⟳ | 双向同步纯文本剪贴板。 |
| 大小上限 ⟳ | 超过上限的文本不会发送（16 KB – 900 KB）。 |

### 安全

显示加密说明、本机配对码（停止共享时可复制或重新生成）、监听**端口** ⟳（默认 `7878`）以及设置的存放位置。

## 命令行

`mouseshare` 与图形界面共用设置，所以在图形界面里配好的内容可以无界面运行。

```text
mouseshare [--config <layout.toml>] <命令>

命令：
  controller   在拥有鼠标键盘的电脑上运行
  target       在需要被控制的电脑上运行
  pair-code    显示本机配对码（--new 生成新的）
```

### `mouseshare target`

```bash
mouseshare target [--listen 0.0.0.0:7878] [--name desk] [--pair-code CODE] [--no-clipboard]
```

启动时会打印配对码。不带 `--pair-code` 时使用本机已保存的配对码（首次使用时自动生成）。

### `mouseshare controller`

```bash
mouseshare controller \
  --connect studio=192.168.1.20:7878 \
  --pair-code studio=7F3KD-9X2MQ \
  [--hotkey "Ctrl+Alt+Esc"] [--no-clipboard]
```

- `--connect id=host:port`：被控端地址（可重复）。省略时通过 mDNS 自动查找。
- `--pair-code CODE` 适用于所有被控端，`--pair-code id=CODE` 只适用于一台（可重复）。
  也会读取 `$MOUSESHARE_PAIR_CODE`，然后是图形界面保存的配对码。
- 不带 `--config` 时使用图形界面保存的排列；带 `--config layout.toml` 则自己提供排列，参见
  [`layout.example.toml`](../layout.example.toml)。

### 编写无界面脚本

```bash
# 在每台被控端上
mouseshare target --name studio --pair-code 7F3KD-9X2MQ &

# 在控制端上
mouseshare --config ~/layout.toml controller --pair-code studio=7F3KD-9X2MQ
```

日志输出到 stderr。

## 文件与配置

| 文件 | 用途 |
|---|---|
| `~/.config/mouseshare/settings.toml` | 偏好设置、设备列表和排列。可以放心附在问题反馈里。 |
| `~/.config/mouseshare/pairing.toml` | **机密。** 配对码（文件权限 `0600`），切勿分享。 |
| `~/.config/autostart/mouseshare.desktop` | 由 *登录时自动打开* 创建。 |

遵循 `$XDG_CONFIG_HOME`。删除 `~/.config/mouseshare` 会重置所有内容（包括首次运行引导）。

## 卸载

```bash
sudo apt remove mouseshare          # .deb
./install.sh --uninstall            # 压缩包安装（若用 --system 安装则同样加上）
rm -rf ~/.config/mouseshare ~/.config/autostart/mouseshare.desktop   # 可选：删除设置
```
